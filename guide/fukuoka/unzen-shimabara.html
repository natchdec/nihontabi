Unzen Onsen + Shimabara: ค้างคืนออนเซ็นบนที่ราบสูงภูเขาไฟ พร้อมปราสาทและคลองปลาคาร์ป

雲仙温泉・島原 · Nagasaki (Unzen / Shimabara)

ออนเซ็นธรรมชาติวัฒนธรรมหิมะถ่ายรูปชิลล์อาหาร

ค้างคืนที่ออนเซ็นบนที่ราบสูงภูเขาไฟ Unzen ซึ่งเย็นกว่าชายฝั่งหลายองศาในฤดูร้อน มีนรกเดือด Unzen Jigoku และฤดูหนาวมีโอกาสเห็นน้ำค้างแข็ง (muhyo) บนเส้น Nita Pass แต่ไม่แน่นอน. เมือง Shimabara มีปราสาทห้าชั้นและคลองน้ำพุที่มีปลาคาร์ปว่ายอยู่; การเดินทางจากฮากาตะราว 4 ชั่วโมงต่อรถไฟ JR, รถไฟท้องถิ่น Shimatetsu และรถบัส

เดินทางจากฟุกุโอกะ (ฐาน Hakata)

ประมาณ 255 นาทีต่อเที่ยว · เปลี่ยนสาย 3 ครั้ง

Hakata Stn → JR Relay Kamome ไป Takeo-Onsen (武雄温泉) → ต่อ Nishi-Kyushu Shinkansen (Kamome) ไป Isahaya (諫早) รวมประมาณ 2 ชม. 17 นาที (ควรเช็คอีกครั้ง) → Shimatetsu ไป Shimabara ~70 นาที (ควรเช็คอีกครั้ง) → รถบัสจาก Shimabara Port ไป Unzen Onsen ~40 นาที (ควรเช็คอีกครั้ง)

กลับ: วันที่สองออกจาก Unzen Onsen ด้วยรถบัสลง Shimabara Port ตามเวลาที่เช็คไว้ (รถบัสเที่ยวไม่บ่อย ควรเช็คตารางก่อน) แล้วนั่ง Shimatetsu ไป Isahaya และ JR ไป Hakata; ถ้ารถบัสพลาดให้เหมาแท็กซี่หรือเลื่อนขึ้นรถเช้า

ค่าเดินทางโดยประมาณ

¥14,580 ไป-กลับ ต่อคน · ประมาณการไป-กลับ: Hakata–Isahaya ~¥5,070 (ประมาณจากเว็บเปรียบเทียบ ควรเช็คอีกครั้ง) + Isahaya–Shimabara ~¥1,460 (ควรเช็คอีกครั้ง) + Shimabara Port–Unzen ~¥760 (ควรเช็คอีกครั้ง) = เที่ยวเดียว ~¥7,290 x2 ≈ ¥14,580 ไม่รวมที่พักและค่าเข้าชมบางแห่ง

ตั๋ว/พาสที่เกี่ยวข้อง

  • JR Kyushu All Kyushu Rail Pass (3 วัน, ราคาออนไลน์) ¥21,000 — ครอบคลุม JR Kyushu รวม Kyushu Shinkansen และ limited express แต่ไม่ครอบคลุม Shimatetsu และรถบัส Unzen; ค่า JR ของทริปนี้ประมาณ ¥10,000 ไป-กลับ จึงไม่คุ้ม (ควรเช็คอีกครั้ง)

เดือนไหนไปดี

เดือนคะแนนหมายเหตุ
ม.ค.4/5หนาวจัดและฟ้าใสบ่อย ออนเซ็นเหมาะมาก; โอกาสเห็นน้ำค้างแข็ง muhyo บนเส้น Nita Pass มีแต่ไม่ทุกวัน (ควรเช็คอีกครั้ง)
ก.พ.4/5หนาวและแห้ง ท้องฟ้าใสบ่อย; ยังมีโอกาส muhyo ในช่วงลมหนาว แต่ไม่รับประกัน (ควรเช็คอีกครั้ง)
มี.ค.3/5เริ่มอุ่นขึ้นแต่เช้ายังหนาว ถนนภูเขาอาจมีน้ำแข็งบ้าง (ควรเช็คอีกครั้ง)
เม.ย.4/5อากาศอ่อนสบาย เหมาะแช่ออนเซ็นและเดินเมือง Shimabara; ซากุระช่วงปลาย มี.ค.–เม.ย. (ควรเช็คอีกครั้ง)
พ.ค.4/5อากาศเย็นสบาย ไม่ร้อนจัด ต้นไม้บนภูเขาเขียวสด เหมาะเดินและแช่ออนเซ็น
มิ.ย.3/5ช่วงฝนชุก อากาศชื้น ทางเดินบนเขาลื่น; ที่ราบสูงเย็นกว่าชายฝั่งแต่หมอกหนาบ่อย
ก.ค.4/5ที่ราบสูง Unzen เย็นกว่าชายฝั่งหลายองศา ออนเซ็นและร้านในร่มสบาย แต่ฝนและพายุไต้ฝุ่นเป็นไปได้
ส.ค.4/5ช่วงเย็นบนที่ราบสูงเย็นสบายกว่าเมืองชายฝั่ง; ระวังพายุไต้ฝุ่นและฝนกระหน่ำ
ก.ย.3/5ไต้ฝุ่นและฝนบ่อย ช่วงปลายเดือนอากาศเริ่มเย็นลง
ต.ค.4/5อากาศแจ่มใส เดินเขาได้สบาย เริ่มเห็นสีใบไม้บนภูเขา (ควรเช็คอีกครั้ง)
พ.ย.4/5อากาศเย็นและใบไม้เปลี่ยนสีราวกลางถึงปลายเดือน; กระเช้าวันสั้นลงในฤดูหนาว (ควรเช็คอีกครั้ง)
ธ.ค.3/5หนาวจัด โอกาส muhyo มีแต่ไม่แน่นอน; ตารางรถบัสช่วงปีใหม่อาจเปลี่ยน (ควรเช็คอีกครั้ง)

ข้อควรรู้ / วันปิด / การจอง

  • Unzen Ropeway (Nita Pass) ไม่เดินในสภาพอากาศเลวร้าย; เวลาเปิดฤดูหนาวไม่ตรงกันระหว่างแหล่งข้อมูล (ราว 08:51 ถึง 16:51–17:11) และราคาไม่ตรงกัน (ควรเช็คอีกครั้งกับผู้ดำเนินการ)
  • ร้านไข่ออนเซ็นที่ Unzen Jigoku Kobo เปิดราว 10:00–16:00/17:00 (ควรเช็คอีกครั้ง)
  • รถบัส Shimabara Port–Unzen ไม่บ่อย ราวชั่วโมงละ 1 เที่ยว; เที่ยวเช้าวันกลับอาจเต็มหรือเปลี่ยนตาราง (ควรเช็คอีกครั้ง)
  • ปราสาท Shimabara ไม่มีวันปิดประจำ เปิด 09:00–17:30 รับเข้าถึง 17:00 (shimabarajou.com)
  • muhyo ไม่ได้เกิดทุกวันและไม่มีการรับประกัน; ถ้าไม่เห็นก็ให้ถือเป็นโอกาสเดินชมบรรยากาศแทน
