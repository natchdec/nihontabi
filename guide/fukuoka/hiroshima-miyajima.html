Miyajima: ประตูลอยน้ำ Itsukushima, ถนน Omotesando และกระเช้า Mt. Misen

宮島 · Hiroshima (Miyajima)

ธรรมชาติถ่ายรูปอาหารวัฒนธรรม

จาก Hiroshima ใช้ JR Sanyo Line ไป Miyajimaguchi ราว 25 นาที ¥420 (japan-guide) แล้วข้ามเรือ JR ~10 นาที ไปเกาะ Miyajima เดินชมศาลเจ้า Itsukushima และประตู torii ลอยน้ำ (ตรวจระดับน้ำขึ้นและสถานะการซ่อม ควรเช็คอีกครั้ง) ไต่ถนนสายศาลเจ้าถึงวัด Daisho-in, Momijidani และกระเช้า Mt. Misen; ใบไม้สวยมากช่วงปลาย ต.ค.–พ.ย.

เดินทางจากฟุกุโอกะ (ฐาน Hakata)

ประมาณ 125 นาทีต่อเที่ยว · เปลี่ยนสาย 2 ครั้ง

Hakata Stn → Shinkansen Sakura/Hikari ~70 นาที (ควรเช็คอีกครั้ง) → Hiroshima Stn → JR Sanyo Line ไป Miyajimaguchi 25 นาที ¥420 (japan-guide) → เรือ JR ~10 นาที ¥200 + ภาษีผู้เยี่ยมชม ¥100 (japan-guide) → เดินถึง Itsukushima ~10 นาที

กลับ: เรือ JR ขากลับจากเกาะถึง Miyajimaguchi ถี่ทุกไม่กี่สิบนาที; ขบวน JR กลับ Hiroshima ราว 19:00–20:00 (ควรเช็คอีกครั้ง); อย่าให้วันกลับผูกกับกระเช้าที่ปิดเร็ว

ค่าเดินทางโดยประมาณ

¥18,480 ไป-กลับ ต่อคน · Shinkansen Hakata–Hiroshima ที่นั่งไม่จอง ~¥8,570 x2 = ¥17,140 (Ekitan ค่าประมาณ ควรเช็คอีกครั้ง) + JR Sanyo Hiroshima–Miyajimaguchi ¥420 x2 = ¥840 (japan-guide) + เรือ JR ¥200 x2 = ¥400 (japan-guide) + ภาษีผู้เยี่ยมชม ¥100 ครั้งเดียวขาลงเกาะ (japan-guide) = ¥18,480. ไม่รวมกระเช้า Mt. Misen (~¥2,000 ไป-กลับ ควรเช็คอีกครั้ง) และค่าเข้าศาลเจ้า (ควรเช็คอีกครั้ง).

เดือนไหนไปดี

เดือนคะแนนหมายเหตุ
ม.ค.3/5หนาว ลมแรงบนเกาะ คนน้อย; หอยนางรมฤดูนี้ดี (ควรเช็คอีกครั้ง)
ก.พ.3/5หนาวและคนน้อยสบาย; เรือลมแรงบางวัน
มี.ค.4/5ซากุระปลายเดือนรอบศาลเจ้าและถนน Omotesando (ราวช่วง ควรเช็คอีกครั้ง)
เม.ย.5/5ซากุระบานราวต้น เม.ย. บนเกาะ; ช่วงวันหยุดคนหนาแน่น (ราวช่วง ควรเช็คอีกครั้ง)
พ.ค.4/5อากาศดี เขียวสด ขึ้นภูเขา Misen สบาย
มิ.ย.2/5ฝนชุก ทางเดินลื่น และน้ำขึ้นสูงบ่อย
ก.ค.2/5ร้อนชื้น ขึ้นกระเช้าถึงยอดวันที่ร้อนจัด; กวางบนเกาะคนแน่น
ส.ค.2/5ร้อนและฝนฟ้าคะนองบ่อย; ตารางกระเช้าอาจปรับ
ก.ย.2/5ไต้ฝุ่นบ่อย กระเช้า/เรืออาจหยุด (ควรเช็คอีกครั้ง)
ต.ค.4/5ใบไม้ (momiji) เริ่มเปลี่ยนสีบนภูเขา Misen และ Momijidani (ราวช่วง ควรเช็คอีกครั้ง)
พ.ย.5/5ใบไม้เปลี่ยนสีเต็มที่บนภูเขา Misen และ Momijidani ดีที่สุดในปี (ราวช่วง ควรเช็คอีกครั้ง)
ธ.ค.3/5ปลายปี ใบไม้ร่วงแล้ว อากาศเย็น ร้านอาจปิดบางช่วงปีใหม่ (ควรเช็คอีกครั้ง)

ข้อควรรู้ / วันปิด / การจอง

  • ศาลเจ้า Itsukushima: การบูรณะประตู torii ลอยน้ำเสร็จแล้วเมื่อ ธ.ค. 2022 (ตามข่าว); แต่เจดีย์ห้าชั้นยังมีนั่งร้านและงานซ่อมถึงราว ธ.ค. 2026 (ควรเช็คอีกครั้ง; ตรวจหน้า construction status ของศาลเจ้า)
  • ประตู torii ลอยน้ำ: จะลอยเห็นชัดเมื่อน้ำขึ้นสูง (ราวระดับ ~250 ซม. ตามแหล่ง); น้ำลงทำให้ torii ตั้งบนพื้นทราย (ควรเช็คอีกครั้ง; ดูตารางน้ำขึ้นน้ำลงรายวัน)
  • กระเช้า Mt. Misen หยุดเมื่อลมแรง ฝนตกหนัก หรือไต้ฝุ่น; เวลาเปิดและค่าโดยสารในแหล่งต่างกัน (ควรเช็คอีกครั้ง)
  • เรือ JR ข้ามฟากมีความถี่สูงแต่ตารางท้ายวันเปลี่ยนตามฤดู (ควรเช็คอีกครั้ง)
