เกียวโตใบไม้แดง: Tofuku-ji, Nanzen-ji, Eikando

京都・東福寺・永観堂・南禅寺(紅葉) · Kyoto

ถ่ายรูปธรรมชาติวัฒนธรรมราตรี

ใบไม้เปลี่ยนสีของเกียวโตมักสูงสุดกลาง-ปลาย พ.ย. โมดูลนี้ออกแบบสองจุดเด่นนอกเส้นทางคิโยมิสึเดิม: เช้า Tofuku-ji และสะพาน Tsutenkyo (Keihan Tofukuji หรือ JR) กลางวัน Nanzen-ji + Eikando ตามทางเดิน Philosopher's Path และตอนเย็นชมไฟส่องใบไม้ที่ Eikando (ถ้าวันนั้นเปิดพิเศษ ควรเช็คอีกครั้ง) ต้องวางแผนเวลาเพราะคนแน่นมาก; สถานีรถไฟจากฐาน Namba ใช้เวลา ~70 นาที

เดินทางจากโอซาก้า (ฐาน Namba)

ประมาณ 75 นาทีต่อเที่ยว · เปลี่ยนสาย 2 ครั้ง

Namba → Metro Midosuji ไป Yodoyabashi ~14 นาที → Keihan Main Line Limited Express ไป Tofukuji ~45-50 นาที | วัน Eikando/Nanzen-ji: Keihan Tofukuji → Sanjo ~12 นาที แล้วเดิน/ Tozai Subway ไป Keage (ควรเช็คอีกครั้ง) | กลับ Sanjo → Yodoyabashi → Metro Namba

กลับ: Keihan ไป Yodoyabashi วิ่งถึงดึก ขบวนสุดท้ายไม่ยืนยัน (ควรเช็คอีกครั้ง) ชมไฟกลางคืนที่ Eikando ถึง ~21:00-21:30 (ควรเช็คอีกครั้ง) เผื่อกลับ

ค่าเดินทางโดยประมาณ

¥1,600 ไป-กลับ ต่อคน · Metro Namba-Yodoyabashi ¥190 + Keihan Yodoyabashi-Tofukuji ¥490 + Keihan Tofukuji-Sanjo ¥240 + Keihan Sanjo-Yodoyabashi ¥490 + Metro ¥190 = ¥1,600 (Yahoo! Transit ยืนยันทุกช่วง); ถ้าต่อ Tozai Subway Sanjo-Keage เพิ่ม ¥220 ต่อเที่ยว

ตั๋ว/พาสที่เกี่ยวข้อง

  • Keihan Kyoto-Osaka Sightseeing Pass 1 วัน ¥1,650 — ค่าจริง ¥1,600 ถูกกว่า pass ¥1,650 (และ pass ไม่รวม Metro ต้องจ่าย ¥380 เพิ่ม; Metro version ¥2,160) จึงไม่ซื้อ (ราคา pass จาก catalog)

ก.พ.2/5หนาว วัดเงียบ ใบไม้ไม่มี

เม.ย.3/5ซากุระริมคลอง Philosopher's Path ปลายมี.ค.-ต้นเม.ย. สวย แต่โมดูลนี้เน้นใบไม้แดง (ควรเช็คอีกครั้ง)
พ.ค.3/5ใบอ่อนเขียวสดที่ Tofuku-ji (Tsutenkyo) ใบไม้เขียวสวยก็ไปได้ (ควรเช็คอีกครั้ง)
มิ.ย.2/5ฤดูฝน ใบไม้เขียวแต่ไม่ใช่ไฮไลต์
ก.ค.2/5ร้อนชื้น
ส.ค.2/5ร้อนจัด
ก.ย.2/5ยังร้อน ใบไม้ยังไม่เปลี่ยนสี
ต.ค.4/5ใบไม้เริ่มเปลี่ยนสีท้ายเดือน (ควรเช็คอีกครั้ง)
พ.ย.5/5ไฮไลต์: ใบไม้แดงสูงสุดราวกลาง-ปลายเดือน Tofuku-ji/Eikando คนแน่นที่สุดของปี Eikando มักเปิดตอนกลางคืนพิเศษ (ควรเช็คอีกครั้ง)
ธ.ค.4/5ใบไม้แดงท้ายฤดู ต้นเดือนยังมีสีที่ Eikando/Nanzen-ji ราว 1-7 ธ.ค. (ควรเช็คอีกครั้ง)

ข้อควรรู้ / วันปิด / การจอง

  • Tofuku-ji/Eikando ค่าเข้าสูงขึ้นช่วงใบไม้แดงและกำหนดชมกลางคืนไม่เหมือนกันทุกปี (ควรเช็คอีกครั้ง)
  • Tsutenkyo ของ Tofuku-ji ต้องเข้าคิวช่วงสุดสัปดาห์ใบไม้แดง บางช่วงจำกัดผู้เข้าชม (ควรเช็คอีกครั้ง)
  • วัดปิดเร็วช่วงฤดูใบไม้ร่วง ราว 16:30-17:00 ยกเว้นวันชมกลางคืน (ควรเช็คอีกครั้ง)
