国営昭和記念公園 · Tokyo (Tachikawa / Akishima)

สวนสนุก/สวนธรรมชาติถ่ายรูปซากุระชิลล์ราตรีใบไม้เปลี่ยนสี

สวนสาธารณะแห่งชาติขนาดใหญ่ในทาจิกาวะ มีทุ่งดอกไม้ตามฤดูกาล สวนญี่ปุ่น และถนนแปะก๊วยสีทอง ปั่นจักรยานเช่าเที่ยวรอบสวนได้ การเดินทางจาก Sendai ใช้ชินกันเซ็นไปโตเกียวแล้วต่อ JR Chuo/Ome Line จึงควรค้างคืนหนึ่งคืน

เดินทางจากเซนได (ฐาน Sendai Station)

ประมาณ 150 นาทีต่อเที่ยว · เปลี่ยนสาย 2 ครั้ง

Sendai Station → Tohoku Shinkansen (Hayabusa) → Tokyo Station → JR Chuo Line (ไป Tachikawa) → JR Ome Line 1 สถานี → Nishi-Tachikawa Station → เดินเข้าประตู Nishi-Tachikawa ของสวน

กลับ: ขากลับจาก Nishi-Tachikawa ไป Tokyo/Sendai: เที่ยวสุดท้ายของ JR Ome Line และ JR Chuo Line ควรเช็คตาราง; ชินกันเซ็นเที่ยวสุดท้ายจาก Tokyo ไป Sendai ควรเช็คก่อนไป (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥24,000 ไป-กลับ ต่อคน · ประมาณการ ยังไม่ได้ตรวจจากตั๋วจริง: Sendai ↔ Tokyo ที่นั่งจองไป-กลับ ประมาณ ¥11,090–11,410 ต่อทาง (ควรเช็คอีกครั้ง) + JR Chuo/Ome Line ช่วงสั้นไม่ถึงพันเยนต่อทาง (ควรเช็คอีกครั้ง); ค่าเข้าสวนผู้ใหญ่ ¥450 ไม่รวม; ค่าอาหารและที่พักไม่รวม

เดือนไหนไปดี

เดือนคะแนนหมายเหตุ
ม.ค.2/5อากาศหนาว ดอกไม้น้อย สวนญี่ปุ่นสงบ อาจมีวันปิดต้นปี (ควรเช็คอีกครั้ง)
ก.พ.2/5อากาศหนาว ต้นไม้ยังไม่ผลิ
มี.ค.3/5เริ่มมีดอกไม้ผลิและต้นไม้เริ่มแตกใบ (ควรเช็คอีกครั้ง)
เม.ย.5/5ช่วงทุ่งทิวลิปและดอกเนโมฟิลา (nemophila) บาน ดอกไม้เยอะที่สุดของปี (ควรเช็คอีกครั้งวันที่บานจริง)
พ.ค.4/5ทิวลิปและทุ่งดอกไม้ยังดี ต้นไม้เขียวสด อากาศอุ่นกำลังดี (ควรเช็คอีกครั้ง)
มิ.ย.3/5ฤดูฝน อากาศชื้น ดอกไม้บางชนิดเริ่มโรย
ก.ค.3/5ร้อนและฝนฟ้าคะนอง ช่วงเย็นมีร่มเงาจากต้นไม้
ส.ค.2/5ร้อนจัดและชื้น ไม่แนะนำให้ปั่นจักรยานกลางวัน
ก.ย.3/5อากาศเริ่มเย็น ทุ่งดอกไม้ตามฤดูกาลเริ่มออก
ต.ค.4/5ทุ่งดอกคอสมอส (cosmos) บานเต็มที่ ท้องฟ้าใส อากาศดี (ควรเช็คอีกครั้ง)
พ.ย.5/5ถนนต้นแปะก๊วย (ginkgo avenue) เหลืองทองสวยที่สุด เดินเที่ยวสบาย (ควรเช็คอีกครั้งวันที่)
ธ.ค.2/5หนาว วันสั้น ต้นไม้ผลัดใบ มีไฟประดับช่วงเทศกาลในบางปี (ควรเช็คอีกครั้ง)

ช่วงใบไม้เปลี่ยนสี (ปีเฉลี่ย)

เริ่ม ปลาย ต.ค. · พีค กลาง พ.ย. · ร่วงหมด/จบ ปลาย พ.ย.

ช่วงทั่วไปของปีเฉลี่ย ไม่ใช่พยากรณ์ปีนี้ ความมั่นใจ: medium · แหล่งอ้างอิง · ควรเช็คพยากรณ์ใบไม้เปลี่ยนสีของปีนั้นก่อนไป

ข้อควรรู้ / วันปิด / การจอง

  • สวนปิดวันปีใหม่ (31 ธ.ค. และ 1 ม.ค.) และมีวันปิดช่วงต้นปีที่ไม่ตรงกันในแต่ละแหล่งข้อมูล (ควรเช็คเว็บสวนก่อนไป)
  • ช่วงจัดไฟ (illumination) บางฤดูประตู Nishi-Tachikawa เปิดเฉพาะบางช่วงและเวลาเข้าสวนต่างจากปกติ (ควรเช็คอีกครั้ง)
  • เวลาเปิดตามผลค้นหาไม่ตรงกัน ตั้งแต่ประมาณ 9:30 ถึง 17:00–18:00 (ควรเช็คอีกครั้ง)
