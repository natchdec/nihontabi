เดินทางจากเซนได (ฐาน Sendai Station)

ประมาณ 215 นาทีต่อเที่ยว · เปลี่ยนสาย 2 ครั้ง

Sendai Station → Tohoku Shinkansen Hayabusa ไป Tokyo (~90 นาที) → เปลี่ยนที่ Tokyo ไป Joetsu Shinkansen ถึง Jomo-Kogen (~70 นาที ตามแหล่ง japan-guide) → รถบัส Kanetsu Kotsu ไป Minakami Station (~25 นาที) → รถบัสต่อไปยัง Tanigawadake Ropeway หรือ Takaragawa Onsen (เวลาและค่าโดยสารยังไม่ได้ยืนยัน)

กลับ: รถบัส Jomo-Kogen ↔ Minakami และรถไฟ JR Joetsu Line มีรอบไม่บ่อย ควรตรวจเที่ยวสุดท้ายของรถบัสและ Joetsu Shinkansen ขากลับก่อนไปทุกครั้ง (ควรเช็คอีกครั้ง); ไปกลับในวันเดียวทำได้ยากเพราะทางเดียวใช้เวลาราว 3.5 ชั่วโมง

ค่าเดินทางโดยประมาณ

¥37,260 ไป-กลับ ต่อคน · ประมาณการ: Sendai ↔ Tokyo Hayabusa reserved ¥11,410 ต่อทาง (ekitan) ; Tokyo ↔ Jomo-Kogen ประมาณ ¥6,500 ต่อทาง (japan-guide ระบุ ¥6,500 และเขียนในเนื้อหาว่า ~¥6,000 ควรเช็คอีกครั้ง) ; รถบัส Jomo-Kogen ↔ Minakami ¥720 ต่อทาง (japan-guide) ; ไป-กลับรวม = 2 × (11,410 + 6,500 + 720) = ¥37,260 ; ไม่รวมรถบัสไป Tanigawadake / Takaragawa และกระเช้า (ยังไม่ได้ยืนยัน)

เดือนไหนไปดี

เดือนคะแนนหมายเหตุ
ม.ค.4/5หิมะหนาในหุบเขาและเป็นช่วงลานสกีเปิด เหมาะกับการแช่ออนเซ็นกลางแจ้งท่ามกลางหิมะ แต่ถนนและรถบัสอาจล่าช้า
ก.พ.4/5หิมะสะสมมาก เป็นช่วงลานสกีและกิจกรรมหน้าหนาวดีที่สุด อากาศหนาวจัด ต้องใส่รองเท้ากันลื่นและเผื่อเวลาเดินทาง
มี.ค.3/5ลานสกียังเปิดบางช่วงแต่หิมะเริ่มละลาย ถนนชื้นและมีโคลนบ้าง
เม.ย.3/5หิมะละลาย เริ่มมีใบอ่อนและฤดูล่องแก่ง (ตามแหล่งทั่วไป ควรเช็คอีกครั้ง) อากาศยังเย็นตอนเช้า
พ.ค.4/5ใบไม้เขียวสด เหมาะเดินป่าและล่องแก่ง อากาศสบาย ไม่ร้อน
มิ.ย.3/5เข้าฤดูฝน อากาศชื้นและฝนตกบ่อย ทางเดินเปียก
ก.ค.4/5อากาศบนภูเขาเย็นกว่าในเมือง เหมาะกับการล่องแก่งและแช่ออนเซ็นกลางแจ้ง (ควรเช็คอีกครั้ง)
ส.ค.4/5ฤดูล่องแก่งและหุบเขาเย็นสบายกว่าเมืองใหญ่ เหมาะกับทริปกลางแจ้ง (ควรเช็คอีกครั้ง)
ก.ย.3/5ช่วงฝนและพายุเข้าได้ อุณหภูมิลดลงตอนปลายเดือน
ต.ค.4/5ใบไม้บนภูเขา Tanigawa เริ่มเปลี่ยนสีกลางถึงปลายเดือน (ควรเช็คอีกครั้ง) อากาศเย็นสบาย
พ.ย.2/5ลมแรงและหนาวขึ้น ใบไม้ร่วง ถนนขึ้นภูเขาบางช่วงเริ่มปิดในฤดูหนาว
ธ.ค.3/5หิมะเริ่มตกและลานสกีเริ่มเปิด แต่วันสั้นและถนนเริ่มลื่น (ควรเช็คอีกครั้ง)

ข้อควรรู้ / วันปิด / การจอง

  • กระเช้า Tanigawadake Ropeway เวลาเปิดและช่วงปิดปีละครั้งยังไม่ได้ยืนยันจากเว็บทางการ (ควรเช็คอีกครั้ง)
  • Takaragawa Onsen เปิดตลอดปีตามแหล่ง thegate12 แต่เวลาเปิด-ปิดรับเข้าไม่ตรงกันระหว่างแหล่ง (9:00–17:00 บางแหล่ง, 10:00–16:00 บางแหล่ง) ควรเช็คก่อนไป
  • รถบัสในหุบเขาอาจลดเที่ยวหรือหยุดวิ่งช่วงหิมะหนัก ควรเช็คตาราง Kanetsu Kotsu ก่อนไป (ควรเช็คอีกครั้ง)
  • ถนนไปสันเขาทานิงาวะช่วงหน้าหนาวอาจปิดหรือมีโซ่หิมะ (ควรเช็คอีกครั้ง)
