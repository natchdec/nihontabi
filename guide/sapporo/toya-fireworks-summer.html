ทะเลสาบ Toya หน้าร้อน: ดอกไม้ไฟทุกคืน ล่องเรือ และ Showa-Shinzan

洞爺湖 ロングラン花火 夏 · Hokkaido (Lake Toya)

เทศกาลราตรีธรรมชาติออนเซ็น

ดอกไม้ไฟ Lake Toya Long Run Fireworks ทุกคืน (ปี 2026: 28 เม.ย.-31 ต.ค. เวลา 20:45-21:05 ราว 20 นาที; ยกเลิกได้เมื่อลมไม่เสถียร ฝนยังจัด) ต้องค้างคืนเพราะรอบ 20:45 ทำให้กลับ Sapporo ไม่ทัน; ปี 2027 ต้องตรวจประกาศ; ในโมดูลนี้เน้นล่องเรือ Toya Kisen (¥1,700 ผู้ใหญ่ ตามรายการ Visit Hokkaido ยังไม่ยืนยันปี 2026), Showa-Shinzan และเดินริมทะเลสาบ ต่างจากโมดูล lake-toya ที่เน้นฤดูหนาว (ควรเช็คอีกครั้ง)

เดินทางจากซัปโปโร (ฐาน Sapporo Station)

ประมาณ 162 นาทีต่อเที่ยว · เปลี่ยนสาย 0 ครั้ง

Donan Bus Sapporo Station → Toyako Onsen ~162-179 นาที ¥3,700 (Yahoo Transit 2 ชม. 59 นาที รวมเดิน; ต้องจอง); ทางเลือก JR Hokuto Sapporo → Toyako ~2 ชม. + บัส Doonan ¥400 (ตั๋ว+ที่นั่ง ¥7,090 ตาม Yahoo)

กลับ: ดอกไม้ไฟ 20:45-21:05 ทำให้ไม่มีรถกลับ Sapporo; ค้างคืนที่ Toyako Onsen แล้วกลับเช้า ตรวจเวลาเที่ยวแรกของบัส (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥7,400 ไป-กลับ ต่อคน · Donan Bus Sapporo–Toyako Onsen ¥3,700 x2 = ¥7,400 (Yahoo Transit ยืนยัน ¥3,700 ต่อเที่ยว ต้องจอง) + ล่องเรือดอกไม้ไฟ Toya Kisen ~¥1,700 (ผู้ใหญ่ ตามรายการ Visit Hokkaido ไม่ยืนยัน; หน้าทางการ laketoya.com ไม่ระบุราคา) ไม่รวมใน singleRT; ที่พัก Toyako Onsen ตรวจแยก (ควรเช็คอีกครั้ง)

ตั๋ว/พาสที่เกี่ยวข้อง

  • Sapporo-Noboribetsu Area Pass ¥10,000 — ไม่ครอบคลุม Toya/บัส Donan; ไม่ซื้อสำหรับโมดูลนี้
