เดินทางจากซัปโปโร (ฐาน Sapporo Station)

ประมาณ 35 นาทีต่อเที่ยว · เปลี่ยนสาย 0 ครั้ง

JR สาย Hakodate Main Line จาก JR Sapporo ไปสถานี Zenibako ราว 35 นาที (ควรเช็คอีกครั้ง); จากนั้นรถบัสหรือแท็กซี่ไปกระเช้าเทนงูยามาและออนเซ็นอาซาริ

กลับ: กระเช้าเที่ยวสุดท้ายขึ้นเวลา 19:48 ลงเวลา 20:00 และรถกลับซัปโปโรเที่ยวสุดท้าย (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥1,600 ไป-กลับ ต่อคน · ค่าโดยสาร JR ซัปโปโร-โอตารุเต็มสายราว ¥800 ต่อเที่ยว; ค่าถึง Zenibako ยังไม่ได้ยืนยัน จึงใช้เพดานของสายเป็นตัวประมาณ x2 = ¥1,600 (ควรเช็คอีกครั้ง); ค่ากระเช้าและค่าออนเซ็นแยกต่างหาก
