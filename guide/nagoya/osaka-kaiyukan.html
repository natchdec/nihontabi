Osaka Kaiyukan + Tempozan: อะควาเรียมยักษ์ ชิงช้าสวรรค์ และไฟริมอ่าว

海遊館・天保山 · Osaka

ชิลล์ราตรีสวนสนุก/สวน

อะควาเรียมในร่มที่ใหญ่ที่สุดแห่งหนึ่งของโลก มีฉลามวาฬ ในย่านท่าเรือ Tempozan ใช้เวลาครึ่งวัน เหมาะวันฝนตก ร้อน และหนาว ต่อด้วยชิงช้าสวรรค์ เรือ Santa Maria และตลาดอาหารริมอ่าว

เดินทางจากนาโกย่า (ฐาน Nagoya Station)

ประมาณ 100 นาทีต่อเที่ยว · เปลี่ยนสาย 2 ครั้ง

Nagoya → Shinkansen Nozomi/Hikari ไป Shin-Osaka ~50 นาที → Osaka Metro Midosuji Line ไป Hommachi → Chuo Line ไป Osakako ~30 นาที → เดิน ~7 นาที (ควรเช็คอีกครั้ง)

กลับ: Shinkansen ขากลับมีถึงราว 21:30–22:00 ตรวจรอบสุดท้าย; อะควาเรียมมักปิด ~20:00 (ตรวจเวลา) (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥14,500 ไป-กลับ ต่อคน · Shinkansen Nagoya–Shin-Osaka ~¥5,900–6,900 ต่อเที่ยว (ประมาณ) + Osaka Metro ~¥300 + บัตรเข้า Kaiyukan ผู้ใหญ่ ~¥2,700 (ราคาแปรตามวัน เว็บทางการ kaiyukan.com) + ชิงช้า/เรือแยก (ควรเช็คอีกครั้ง)

คำถามที่พบบ่อย

จาก Nagoya ไป Osaka Kaiyukan + Tempozan ใช้เวลาเดินทางเท่าไหร่?

ประมาณ 100 นาทีต่อเที่ยวจากฐาน Nagoya Station เปลี่ยนสาย 2 ครั้ง (Nagoya → Shinkansen Nozomi/Hikari ไป Shin-Osaka ~50 นาที → Osaka Metro Midosuji Line ไป Hommachi → Chuo Line ไป Osakako ~30 นาที → เดิน ~7 นาที (ควรเช็คอีกครั้ง))

Osaka Kaiyukan + Tempozan ไปเดือนไหนดี?
