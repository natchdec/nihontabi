Shima / Kashikojima: อ่าว Ago ล่องเรือ Spain Village หอยนางรมและหน้าหนาวไฟประดับ (ค้างคืน)

志摩・賢島 · Mie (Shima / Ago Bay)

ธรรมชาติอาหารราตรีสวนสนุก/สวนถ่ายรูป

ชายฝั่ง Ise-Shima ปลายสาย Kintetsu ล่องเรือชมเกาะน้อยใหญ่ในอ่าว Ago ชมสาวดำน้ำ (ama) กินหอยนางรม (ธ.ค.–มี.ค.) และสวนสนุก Shima Spain Village ที่มีไฟประดับฤดูหนาวและสระน้ำฤดูร้อน (ค้างคืน)

เปิดแอปวางแผน นาโกย่า →

เดินทางจากนาโกย่า (ฐาน Nagoya Station)

ประมาณ 130 นาทีต่อเที่ยว · เปลี่ยนสาย 0 ครั้ง

Nagoya Station → Kintetsu Limited Express Shimakaze ไป Kashikojima ~2 ชม. 5 นาที (ตรงไม่เปลี่ยน; ¥5,060 ตามที่ตรวจ ควรเช็คอีกครั้ง) → ไป Shima Spain Village ลง Shima-Isobe ก่อนถึง (ควรเช็คอีกครั้ง)

กลับ: Shimakaze กลับ Nagoya มีเป็นรอบ (ตรวจตาราง; ตั้งเป้าเที่ยวสุดท้ายเดินทางก่อน 18:00) ถ้าค้างคืนใช้ขบวนรุ่งเช้า (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥10,120 ไป-กลับ ต่อคน · Kintetsu Nagoya–Kashikojima ¥5,060 ต่อเที่ยว (ที่นั่งสำรอง Shimakaze; ควรเช็คอีกครั้ง) + เรือ Ago Bay ราว ¥1,500–3,000 + Spain Village Passport ~¥5,700–5,900 (ควรเช็คอีกครั้ง) + ที่พักค้างคืน

ข้อควรรู้ / วันปิด / การจอง

  • Spain Village มีวันปิดตามปฏิทินทางการ (บางวันทำงานซ่อม) ตรวจก่อนไป (ควรเช็คอีกครั้ง)
  • เรือ Ago Bay หยุดในลมแรง/ไต้ฝุ่น (ควรเช็คอีกครั้ง)
  • ร้านอาหารทะเลปิดวันเฉพาะร้าน (ควรเช็คอีกครั้ง)
