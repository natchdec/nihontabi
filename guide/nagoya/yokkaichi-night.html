Yokkaichi: ไฟยามค่ำโรงงานริมอ่าว + ตึกชมวิวท่าเรือ + ทงเทะกิ

四日市・コンビナート夜景 · Mie (Yokkaichi)

ราตรีถ่ายรูปอาหารชิลล์

ทริปเย็น-ค่ำจาก Nagoya แค่ ~40 นาที ชมแสงไฟโรงกลั่นริมอ่าวยามค่ำซึ่งอากาศใสในฤดูหนาวจะงามที่สุด ขึ้นตึก Port Building ชมวิวท่าเรือ ทานทงเทะกิ (หมูทอดซอสเข้ม) ของเมือง และขนม Nagamochi

เดินทางจากนาโกย่า (ฐาน Nagoya Station)

ประมาณ 55 นาทีต่อเที่ยว · เปลี่ยนสาย 1 ครั้ง

Nagoya Station → Kintetsu Nagoya Line (Rapid Express) ไป Kintetsu-Yokkaichi ~35 นาที (หรือ JR Kansai Line ไป Yokkaichi ~40 นาที) จากสถานีไป Port Building โดยบัสหรือแท็กซี่ ~15 นาที (ควรเช็คอีกครั้ง)

กลับ: ขากลับ Kintetsu/JR มีถึงดึก (ราว 23:00) ตรวจตารางจริง; ถ้าขึ้นเรือครัวไฟค่ำ ให้จองรอบที่ไม่เกิน 20:30 (ควรเช็คอีกครั้ง)

ค่าเดินทางโดยประมาณ

¥1,300 ไป-กลับ ต่อคน · Kintetsu Nagoya–Kintetsu-Yokkaichi ประมาณ ¥640 ต่อเที่ยว (ควรเช็คอีกครั้ง) + บัส/แท็กซี่ไป Port Building ราว ¥200–1,500 + ค่าขึ้นชมวิว/เรือคร่าวๆ ¥200–3,000 (ควรเช็คอีกครั้ง)

เดือนไหนไปดี

เดือนคะแนนหมายเหตุ
ม.ค.5/5อากาศใส เห็นแสงไฟโรงงานคมที่สุดของปี หนาวมากช่วงค่ำ เตรียมเสื้อกันหนาว
ก.พ.5/5ท้องฟ้าใสต่อเนื่อง ไฟสวย คนน้อย ลมทะเลเย็น
มี.ค.4/5อากาศเริ่มอุ่น ไฟยังสวย
เม.ย.3/5ฝนบ้าง ค่ำเริ่มช้าลงทำให้ต้องรอ
พ.ค.3/5หมอกเบาบางบ้าง ค่ำช้า ไฟสวยเมื่อฟ้าใส
มิ.ย.3/5ฤดูฝน ฟ้าไม่ใส ไปเฉพาะวันฟ้าเปิด
ก.ค.4/5ร้อนกลางวัน แต่ช่วงค่ำลมทะเลเย็น แสงไฟสวย ต้องเริ่มชมหลังพระอาทิตย์ตกราว 19:30 (ควรเช็คอีกครั้ง)
ส.ค.4/5ร้อนจัด ไปเย็นค่ำได้สบาย มีดอกไม้ไฟ Yokkaichi (ช่วงต้น/กลาง ส.ค.) (ควรเช็คอีกครั้ง)
ก.ย.4/5พายุไต้ฝุ่นมีผลบ้าง อากาศเริ่มเย็น ไฟสวย
ต.ค.4/5อากาศใสเริ่มดี ค่ำเร็ว แสงสวย
พ.ย.5/5อากาศใสเย็น ไฟสวยมาก ท้องฟ้าค่ำเร็ว (เริ่มชมราว 17:00)
ธ.ค.5/5ค่ำเร็ว อากาศใส ไฟสวย มักมีไฟประดับปลายปีในเมือง (ควรเช็คอีกครั้ง)

ข้อควรรู้ / วันปิด / การจอง

  • Port Building (うみてらす14) มีวันหยุดตามที่ทางการประกาศ (มักปิดวันจันทร์) ตรวจก่อนไป (ควรเช็คอีกครั้ง)
  • เรือชมไฟ (ถ้ามี) เปิดเป็นรอบ ต้องจอง (ควรเช็คอีกครั้ง)
  • ร้านอาหารท้องถิ่นบางร้านปิดวันเฉพาะ
